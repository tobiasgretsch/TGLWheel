# Lessons Learned

| Date | Category | What went wrong | Rule derived |
|------|----------|----------------|--------------|
| 2026-04-16 | Refactoring | When extracting handler functions from a Flask route, the `@app.route` decorator was left above the first extracted function (`_handle_spin`) instead of being moved to the actual view function (`send_command`). Flask silently registered `_handle_spin` as the endpoint handler. | When refactoring code below a decorator, always verify the decorator stays attached to the correct function. Check the decorator-to-function binding after any insertion between them. |
| 2026-09-13 | Tooling | Passing a large JS block (template literals, quotes) through a bash heredoc into `py -3 -` failed with a shell quoting error, wasting a round trip. | For multi-line patches containing mixed quotes, write the patch script to the scratchpad with the Write tool and run it from there instead of inlining it in a heredoc. |
| 2026-10-06 | Sync | The server sent the winner as an index into its active list, but the display indexed its own list (failed image loads dropped, list never refreshed). The two lists could differ, so the wheel landed on a different event than the server disabled. | Identify shared entities across clients by a stable key (filename), never by a position in independently built lists. |
| 2026-10-06 | State linkage | The result timer only started on a clock "stopped → running" transition. WEITER pressed during the 7.5 s spin animation hit `idle` and was lost, so the result screen froze. | When state B follows state A, check A's current value when B is entered, not only A's transitions. |
| 2026-10-06 | Idempotency | `result_finished` was idempotent but not phase-guarded: a late retry after the next spin would have aborted that spin. | Idempotent callbacks must also be scoped to the phase they belong to. |
| 2026-10-06 | Tooling | Python `open(..., "w")` on Windows wrote CRLF into LF files. Headless Chrome throttled timers in the background display tab, so timing checks failed spuriously. | Patch files with `newline=""` (or re-normalize line endings). Start headless Chrome with `--disable-background-timer-throttling --disable-renderer-backgrounding` for multi-tab E2E checks. |
| 2026-10-06 | UI layering | The popup card used the translucent `--color-surface` (6 % white), so the page showed through. The status toast had no z-index and sat behind the popup overlay, which hid error messages while a popup was open. | Overlay content needs an opaque background (surface over `--color-bg`). Anything that reports feedback (toasts) must sit above every overlay. |
